<h1>ArzMedPanel</h1>

Удобная и быстрая панель медика для Arizona RP на MoonLoader и mimgui.

---

### ⌨️ Управление и команды:

| Клавиша / Команда | Действие |
| :--- | :--- |
| **`F3`** | **Открыть / закрыть панель** |
| **`R Shift`** | **Подтвердить действие из всплывающей плашки** |
| **`F12`** | **Остановить текущий бинд, отыгровку или забор крови** |
| **`ESC`** | Закрыть панель, редактор бинда, меню выдачи или забора крови (без выхода в паузу игры) |
| **`/medpanel`** | Альтернативная команда для открытия панели |
| **`/medcmd`** | Просмотр и смена команд (например: `/medcmd 1 heal`) |
| **`/medmode`** | Выбор режима отправки команд в чат |
| **`/medlisten`** | Включить / выключить прослушку просьб пациентов (`debug` — отладка) |
| **`/medauto`** | Включить / выключить автономный режим (отыгровки и перехват команд `/hl`, `/med`, `/hlb`, `/recept`, `/ant`) |
| **`/medtag`** | Установить тег фракции для отыгровок (например: `/medtag МЗ`) |
| **`/medprice`** | Просмотр и настройка цен (`heal`, `hlb`, `med7`, `med14`, `med30`, `med60`, `recept`, `ant`) |
| **`/medblood`** | Остановить текущую сессию забора крови |
| **`/medstop`** | Остановить текущий бинд или автономную отыгровку |
| **`/medtest`** | Тест распознавания фразы (например: `/medtest 519 лекни`) |

( Только v1.3 )
---

### 📦 Требования:
1. **[MoonLoader](https://blast.hk/moonloader/)**
2. **Arizona Helper**
3. Библиотека **mimgui**
